NASAZENÍ NA NETLIFY
1. Rozbal ZIP.
2. Nahraj celý projekt do GitHub repozitáře.
3. V Netlify zvol Add new project > Import an existing project a vyber repozitář.
4. Build command ponech prázdný; publish directory: . ; functions: netlify/functions.
5. Deploy. Netlify automaticky nainstaluje @netlify/blobs z package.json.
6. Otevři vygenerovaný odkaz a rozešli ho účastníkům.
POZOR: Pouhé přetažení statické složky na Netlify Drop bez instalace závislostí nemusí funkci spustit. Použij Git deployment.
Hlasování je veřejné pro každého, kdo má odkaz. Změna hlasu je vázána na identifikátor uložený v prohlížeči, nikoliv na účet. Není určeno pro citlivá data.
